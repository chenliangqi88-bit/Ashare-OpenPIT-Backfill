# A-share Open-PIT Real Backfill

Remote execution repository for V3.0.3-H1 BF1 real-market pilot.

The first workflow backfills real unadjusted A-share market data for 2018–2026 using BaoStock on GitHub-hosted runners. A successful market bootstrap is **not** full BF1 Real Acceptance: official listing/delisting/ST/suspension evidence, corporate actions, survivorship audit, and delisting terminal-value coverage are still mandatory.
